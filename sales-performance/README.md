# 출발월별 발매실적

기존 보호 화면과 동일한 비밀번호로 접근하는 별도 발매실적 뷰어입니다.
자료는 AES-256-GCM으로 암호화되어 있으며 비밀번호와 원본 RAW는 게시하지 않습니다.
BI·하드블럭 ver1/ver2·업체별 상세·노선 curve 및 날짜별 누적 Excel 다운로드를 제공합니다.
작성일별 정적 스냅샷이며, 로컬 원본 파일 보기는 해당 PC의 로컬 서버를 이용합니다.

하드블럭 계약 탭에서 제공된 계약 원본을 대노선·노선별로 조회하고 원본 그대로 다운로드할 수 있습니다. 새 파일은 실행 중인 로컬 대시보드 서버에 영구 보관하며, 계약 원본 GitHub 게시 버튼으로 암호화해 공유합니다. 업로드한 문서는 기존 원본을 덮어쓰지 않습니다.
