# Protected browser viewer

This repository publishes a password entry screen and an encrypted payload.
The payload is decrypted only in the browser after a correct password is supplied.
No password, raw source dataset, private analysis source code, or decryption key is stored in this repository.

Search engines are instructed not to index the viewer. The ciphertext is publicly downloadable; confidentiality depends on the separately distributed high-entropy password and authenticated encryption.

The repository owner distributes access details separately. This is a static snapshot, not a live connection to the source system.
